Montaje de un PC

Descripción

💻En esta página veremos los componentes necesarios para realizar un buen montaje de un pc, empezaremos mecionando que componentes vamos a necesitar, algunas herramientas y materiales necesarios, y como realizar el montaje del mismo💻

Componentes necesarios

Placa base
Esta va a ser la base de nuestro pc donde vamos a colocar todos los componentes


Procesador
es el componente de hardware que funciona como el cerebro de un ordenador o dispositivo electrónico


Memoria RAM
Imagina que la RAM es como un escritorio o una mesa de trabajo. Cuanto más grande sea esa mesa, más libros y herramientas podrás tener abiertos al mismo tiempo sin desorden y trabajarás de forma más rápida.


Tarjeta gráfica(opcional)
Este componente es opcional, funciona como el musculo de nuestro ordenador, necesario para tareas pesadas como pueden ser juegos o renderizar videos etc...


Almacenamiento
componente de hardware encargado de guardar y conservar datos e información de forma permanente a largo plazo.


Fuente de alimentación
Es el componente que da energía a todo el ordenador, se debe tener suficientes watts para alimentar a todos los componente


Caja
Es la estructura donde nosotros vamos a guardar todos los componentes internos del ordenador

Herramientas necesarias

Herramientas
  • Destornillador
  • Pasta térmica
  • Bridas o cintas para organizar cables
Materiales
  • Pasta termica
  • Alcohol isopropilico

Pasos a seguir

  1. Instalar la CPU en la placa base
  2. Instalar la memoria RAM en la placa base
  3. Instalar el almacenamiento en la placa base
  4. Instalar la fuente de alimentación en la caja
  5. Instalar la placa base en la caja
  6. Conectar los cables de alimentación a la placa base y a los componentes
  7. Instalar la tarjeta gráfica (si es necesario)
  8. Cerrar la caja y conectar el monitor, teclado y ratón
